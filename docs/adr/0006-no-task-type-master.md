# 0006: タスク種別マスタを持たない

## Status

Accepted

## Context

Step1〜2の検討時、タスクを種別(例: 開発・調査・雑務など)で分類するマスタテーブル(`task_types`)を持たせるかどうかを検討した。アプリのテーマは「タスクの大変さの想定と実績のギャップを振り返る」ことであり、種別分類自体は課題の核心ではない。

## Decision

タスク種別による分類は行わない。`task_types`のようなマスタテーブルは設けず、`tasks`テーブルは種別カラムを持たない。

## Consequences

- スキーマがシンプルになり、`users`と`tasks`の2テーブルのみで完結する
- 将来「種別ごとの傾向を見たい」といった要求が出た場合は、別途マスタテーブルとカラム追加、および既存データのマイグレーションが必要になる
