# 0001: 実装言語にGoを採用する

## Status

Accepted

## Context

DevOpsキャンプ最終課題Step1(バックエンド1)で使用言語を決める必要があった。キャンプ側の選択肢の一つとしてGoが提示されており、参加者自身の学習目的にも合致していた。

## Decision

バックエンドの実装言語としてGoを採用する。

## Consequences

- 標準ライブラリが充実しているため、Step2で要求されるフレームワーク不使用の実装([0002](./0002-net-http-only.md))と相性が良い
- 参加者にとって新しい言語であり、学習コストは発生するが、それ自体がキャンプの目的の一つ
