「✎ 編集」を押すとその行がリスト名の入力欄に差し替わり、保存でPATCH /lists/{id}を呼ぶ。「🗑 削除」は確認ダイアログを経由してDELETE /lists/{id}を呼ぶ。リストを削除してもタスクは消えず、所属していたタスクのlist_idがnullに戻るだけ(ON DELETE SET NULL、ADR-0021)。新規作成はPOST /listsで、作成後は一覧に追記されS-03のリスト絞り込みドロップダウンの選択肢にも反映される

読み方: 実線の枠は画面自体、破線の枠は入力欄やプレースホルダを表す。差し色(青)はクリック可能な操作(ボタン・リンク・選択中の値・▸▾の展開矢印)を示す。タスクの作成・編集・詳細確認はすべてモーダル方式(docs/assignment/step4.mdの「設計判断の背景」参照)であることを示すため、呼び出し元の画面を薄暗くした背景の上に重ねて描いている。画面一覧の詳細は docs/SCREEN_LIST.md、遷移の詳細は docs/SCREEN_FLOW.md、Step4提出後の変更点は docs/assignment/step5.md を参照。
